# ESP32 DevKit V1: ST25R3916, MIFARE Classic 1K, microSD и SSD1315

Прошивка: [`firmware/Classic1kRam/Classic1kRam.ino`](firmware/Classic1kRam/Classic1kRam.ino). Она считывает блоки **своей тестовой** MIFARE Classic 1K, сохраняет текстовый дамп на microSD и позволяет выбрать файл по имени для **эмуляции только UID, ATQA и SAK**. Эмуляции памяти, Crypto1 и ответа на `AUTH/READ` в режиме карты **нет**. UID, совпавший с оригиналом в NFC Tools, не означает, что работает полноценная копия карты. Физическая карта никогда не записывается.

На дисплее три пункта: **Read + save** (чтение и сохранение), **Emulate file** (выбор имени из microSD) и **PC file manager** (подсказки по Serial-командам). Файлы можно посмотреть и переименовать с компьютера через USB-Serial. **ESP32 DevKit V1 не предоставляет SD как USB-накопитель**: проводник Windows не увидит её как диск.

## Подключение

Все земли общие. GPIO ESP32 работают с логикой **3,3 В**; подавать 5 В на входы ESP32 нельзя. Перед проводкой отключите питание. Выбранные контакты дисплея, кнопок и SD задаются константами в начале скетча — поменяйте их, если у вашей платы другая разводка.

| ELECHOUSE ST25R3916 (SPI) | ESP32 DevKit V1 |
|---|---|
| SCLK/SCL | GPIO18 |
| MISO/SDA | GPIO19 |
| MOSI | GPIO23 |
| CS | GPIO5 |
| IRQ | GPIO4 |
| **5V** | **VIN/5V**, если ESP32 запитан от USB |
| GND | GND |

На показанном ранее модуле вход подписан **5V**: используется питание 5 В со встроенным стабилизатором согласно [инструкции ELECHOUSE](https://www.elechouse.com/docs/st25r3916/), а SPI-сигналы ESP32 остаются 3,3 В. Перемычка `I2C` на NFC-модуле должна быть разомкнута (режим SPI). Не путайте `VIN/5V` и `3V3` на ESP32; проверьте напряжение мультиметром прямо на модуле. Питание SD-модуля **зависит от его модели**: у одних вход только 3,3 В, у других есть стабилизатор и вход 5 В. Используйте маркировку/схему своего модуля и убедитесь, что его **MISO не выдаёт 5 В** в ESP32.

| SSD1315 128×64, I²C | ESP32 |
|---|---|
| SDA | GPIO21 |
| SCL | GPIO22 |
| VCC | 3V3 (если модуль рассчитан на 3,3 В) |
| GND | GND |

Адрес дисплея по умолчанию `0x3C`; если ваш модуль использует `0x3D`, измените `OLED_ADDR`. Для кнопок **предполагаются четыре независимых контакта, замыкающих GPIO на GND (active low)**. Включена внутренняя подтяжка `INPUT_PULLUP`:

| Кнопка | GPIO | Действие |
|---|---:|---|
| UP | 32 | Предыдущий пункт / файл |
| DOWN | 33 | Следующий пункт / файл |
| OK | 25 | Выбрать / запустить |
| BACK | 26 | Остановить режим / вернуться в меню |

Это **настраиваемое назначение**, а не заявленная распиновка вашего дисплейного модуля: физические контакты кнопок следует проверить по его маркировке. Если они объединены в ADC-лестницу или I²C-расширитель, описанное подключение и текущий код кнопок не подходят.

| SPI microSD | ESP32 |
|---|---:|
| SCK / CLK | GPIO18 (общая шина с NFC) |
| MISO / DO | GPIO19 (общая шина) |
| MOSI / DI | GPIO23 (общая шина) |
| CS | GPIO13 (отдельный выбор устройства) |
| VCC | По спецификации **вашего** SD-модуля |
| GND | GND |

NFC использует CS=5, microSD — CS=13. Оба устройства должны отпускать MISO при неактивном CS. Карту microSD отформатируйте в **FAT32**; вставьте её до включения ESP32. При проблемах с SD проверьте её модуль, питание, CS и общую землю.

## Установка

В Arduino IDE выберите **ESP32 Dev Module**, Serial Monitor **115200 бод** и окончание строки **Newline** (либо Both NL & CR). Установите:

- `ST25R3916_ELECHOUSE` и `NFC-RFAL` **из одной ревизии** [ELECHOUSE ESP32-библиотеки](https://github.com/wilson-elechouse/ST25R3916) (ориентир: `76d85da7b7e9cb89042eb0e31e070fec91030abb`);
- [U8g2](https://github.com/olikraus/u8g2) для драйвера SSD1315;
- `SPI`, `Wire`, `SD` — входят в Arduino-ESP32.

Сначала убедитесь, что штатный пример `ESP32_SPI_scan_14443A_led` с теми же проводами видит UID. После запуска этого скетча ожидаются строки `NFC init: 0` и `microSD ready`. Если `microSD failed`, команда `SDINIT` повторит монтирование; при `NFC init` с ненулевым кодом попробуйте `INIT` после стабилизации питания. При проблемах с радиочипом не пытайтесь обходить проверку идентификатора.

## Чтение и формат файла

В меню нажмите **Read + save** либо отправьте `READ`. Поднесите MIFARE Classic 1K с **4-байтовым UID и SAK 08**. Прошивка повторно активирует карту перед каждым сектором, проверяет UID, аутентифицирует секторы 0–15 по **Key A `FF FF FF FF FF FF`** и читает блоки 0–63. Ключи других секторов можно изменить локально в `keyA[sector]` в скетче. Не отправляйте секретные ключи в переписке. После завершения создаётся файл `D000001.TXT`, `D000002.TXT` и т. д. Старые файлы не перезаписываются. BACK/`STOP` прерывает чтение без автоматического сохранения.

Формат — обычный UTF-8/ASCII текст: `RFID_UID_DUMP_V1`, строки `UID=`, `ATQA=`, `SAK=`, `KEYS=NOT_STORED`, далее `B00=` … `B63=`. Прочитанный блок содержит 32 шестнадцатеричных символа, непрочитанный — `--`. При частичной аутентификации файл **частичный**, а не полный дамп. Шесть байт Key A и шесть байт Key B в трейлерах маскируются нулями: обычное чтение не восстанавливает ключи. Для карты другого типа сохраняется только UID/ATQA/SAK и `--` для всех блоков. Файлы могут содержать конфиденциальные данные; не публикуйте дамп действующей карты доступа.

## Эмуляция и файлы через Serial

В меню **Emulate file** выберите имя стрелками и нажмите OK. Будут загружены UID/ATQA/SAK; **блоки файла не передаются читателю**. Поддерживаются UID длиной 4 или 7 байт (10-байтный UID можно сохранить, но не эмулировать в этом режиме RFAL). BACK останавливает режим. NFC Tools может увидеть идентификатор, но это не подтверждает аутентификацию MIFARE Classic.

Для компьютера откройте Serial Monitor/терминал (115200, Newline). Режим меню **PC file manager** показывает подсказку; доступны те же команды независимо от экрана. Перед операциями с SD остановите чтение/эмуляцию командой `STOP`:

| Команда | Действие |
|---|---|
| `HELP` | Подсказка |
| `STATUS`, `UID` | Состояние и выбранный UID |
| `READ` | Считать карту и сохранить текстовый дамп |
| `FILES` | Список `.TXT` файлов в корне microSD |
| `CAT D000001.TXT` | Вывести весь файл в Serial (можно скопировать/сохранить лог на ПК) |
| `RENAME D000001.TXT TEST.TXT` | Переименовать файл; существующий файл не заменяется |
| `EMU TEST.TXT` | Загрузить указанный файл и включить UID-only режим |
| `INIT` | Повторить неудачную инициализацию NFC |
| `STOP` | Остановить NFC, не стирая выбранные данные из RAM |
| `SDINIT` | Повторить монтирование microSD |

Поддерживаются только имена в **корне SD формата 8.3**: 1–8 символов `A–Z`, `0–9`, `_`, `-` и расширение `.TXT`. Пути и вложенные папки запрещены. Дисплейный список ограничен первыми 40 подходящими файлами, но `FILES`, `CAT`, `RENAME` доступны по имени через Serial. Эта версия пока **не проверена на физическом SD-модуле и дисплее пользователя**: проверьте цепи питания и контакты перед включением.
